# PERFORMA — Loja Virtual de Artigos Esportivos

## 1. Apresentação do Projeto

A PERFORMA é uma proposta de loja virtual voltada à comercialização de artigos esportivos, desenvolvida como projeto acadêmico de aplicação dos conhecimentos adquiridos em desenvolvimento web.

A ideia surgiu a partir de uma proposta de empreendimento familiar, que busca utilizar o comércio eletrônico como uma alternativa para a comercialização de produtos esportivos e a geração de renda complementar.

A partir dessa proposta, foi desenvolvido um protótipo de loja virtual com o objetivo de apresentar uma experiência de navegação intuitiva, organizada e visualmente atrativa, permitindo que os usuários conheçam os produtos e interajam com os principais recursos de uma plataforma de comércio eletrônico.

O projeto foi desenvolvido no formato One Page, concentrando as principais informações e funcionalidades em uma única página, com navegação dinâmica entre suas seções.

## 2. Objetivos

O principal objetivo da PERFORMA é desenvolver uma interface de comércio eletrônico que demonstre a aplicação prática de tecnologias de desenvolvimento front-end.

Entre os objetivos específicos estão:

- Desenvolver uma interface organizada e intuitiva para a apresentação de produtos esportivos.
- Aplicar conceitos de responsividade e experiência do usuário.
- Implementar funcionalidades dinâmicas utilizando JavaScript.
- Desenvolver mecanismos de interação, como pesquisa, filtros e carrinho de compras demonstrativo.
- Criar um formulário de contato com validação de dados.
- Aplicar boas práticas de organização e estruturação de código.

## 3. Identidade Visual e Interface

A identidade visual da PERFORMA foi desenvolvida considerando características associadas ao universo esportivo, buscando transmitir energia, dinamismo e confiança.

A escolha da paleta de cores foi orientada por conceitos da teoria das cores e pelo contraste entre os elementos, de modo a proporcionar uma interface visualmente equilibrada e facilitar a identificação das informações.

As principais escolhas foram:

- **Laranja:** utilizado como cor de destaque, associado à energia, ao movimento e ao dinamismo.
- **Azul-escuro:** utilizado para transmitir estabilidade, confiança e proporcionar contraste com os elementos de destaque.
- **Preto e branco:** aplicados na composição dos elementos visuais, contribuindo para a legibilidade e a organização da interface.

Os ícones seguem uma proposta predominantemente monocromática, facilitando sua identificação e mantendo a consistência visual.

Antes do desenvolvimento da interface, foi elaborado um protótipo de média fidelidade, utilizado como referência para a organização dos elementos, distribuição das seções e definição da estrutura visual da página.

O layout foi desenvolvido considerando princípios de usabilidade, hierarquia visual, contraste e responsividade.

## 4. Tecnologias Utilizadas

O desenvolvimento da PERFORMA utiliza tecnologias voltadas à construção de interfaces web e à implementação de funcionalidades no navegador.

| Tecnologia | Aplicação no projeto |
|---|---|
| HTML5 | Estruturação e organização do conteúdo da página. |
| CSS3 | Estilização, identidade visual, layout e responsividade. |
| Bootstrap 5 | Utilização de recursos de interface e componentes responsivos. |
| JavaScript ES6+ | Implementação de funcionalidades dinâmicas e interatividade. |
| GitHub Pages | Hospedagem e publicação da aplicação. |

O projeto utiliza módulos nativos de JavaScript, permitindo a separação das funcionalidades em diferentes arquivos e facilitando a manutenção e organização do código.

## 5. Recursos e Implementações em JavaScript

O JavaScript é responsável por controlar as interações da aplicação e proporcionar uma experiência dinâmica ao usuário.

Entre os recursos implementados, destacam-se:

- **Navegação dinâmica:** interação com o menu e direcionamento entre as seções da página.
- **Pesquisa de produtos:** permite localizar produtos de acordo com os termos informados pelo usuário.
- **Filtros:** possibilitam organizar e visualizar produtos conforme critérios disponíveis na interface.
- **Carrinho de compras:** permite adicionar e remover produtos, além de acompanhar os itens selecionados.
- **Validação de formulário:** verifica o preenchimento dos campos obrigatórios e apresenta feedback ao usuário.
- **Armazenamento local:** utilização do localStorage para preservar determinadas informações no navegador, quando aplicável.

A organização do JavaScript em módulos permite dividir responsabilidades e evitar que todas as funcionalidades fiquem concentradas em um único arquivo.

## 7. Formulário de Contato

A aplicação possui um formulário de contato destinado à interação entre os usuários e a loja.

O formulário utiliza validação em JavaScript para verificar o preenchimento dos campos e fornecer mensagens de feedback durante a interação.

Para possibilitar o envio de mensagens sem a necessidade de desenvolver um servidor próprio, pode ser utilizado um serviço externo, como o Formspree.

A integração com esse serviço depende da configuração de um endpoint válido.

## 9. Considerações Finais

O desenvolvimento da PERFORMA possibilitou aplicar conhecimentos de estruturação, estilização e programação web em uma proposta com contexto prático.

Além da construção da interface, o projeto permitiu explorar conceitos de experiência do usuário, organização de código, modularização de JavaScript, responsividade e implementação de funcionalidades interativas.

A proposta demonstra como tecnologias de desenvolvimento front-end podem ser utilizadas na construção de uma interface de comércio eletrônico, transformando uma ideia inicial de empreendimento em um protótipo navegável e acessível pela internet.
